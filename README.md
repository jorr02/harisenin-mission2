# VideoBelajar (React)

Mission 1–2 – ReactJS. Pages: `/login`, `/register`, `/home`.

Mission 2: `/home` is interactive — course data lives in a `useState` array of objects in `Home.jsx` (parent) and is passed to child components via props. You can get (filter by category tab), add, edit, and delete courses directly on the page.

```bash
npm install
npm run dev     # local
npm run build   # production build in dist/
```

Stack: Vite, React, React Router, Tailwind CSS v4. Deploy `dist/` to Vercel or Netlify (`vercel.json` handles SPA routing).
